# 금고 탈출 게임 설계 기록 (2026-11-16)

> 기존 계정 Claude 프로젝트 문서를 옮긴 것. 최신 상태는 저장소 루트의 HANDOFF.md 2절을 기준으로 한다.

## 결정 사항
- 학습지 업로드 대신 **정답을 맞혀야 넘어가는 게임**으로 학습 확인
- 조합: ② 차시별 금고 방탈출 + ③ 단원 스토리 RPG + ④ 금융 도감 + ⑤ 단원 보스전 (영상은 교실에서 함께 보므로 영상 관문은 제외)
- 확인 방식: **Firebase 기록** — 학생은 반 코드 + 번호(익명 로그인, 이름·이메일 없음), 교사는 구글 로그인으로 자기 반만 열람
- 학습지 과제 ③ → 금고 마지막 방 **1~2줄 서술** (오늘 낱말 1개 이상, 20자 이상이어야 제출)

## 처음에 제시했던 아이디어 6가지 (참고)
1. 영상 관문 — 영상 퀴즈에서 정답을 눌러야 영상이 이어짐 (고르지 않음: 영상은 교실에서 함께 봄)
2. 금고 방탈출 — 자물쇠마다 비밀번호 한 자리, 틀리면 힌트 (선택)
3. 용돈 생존 RPG「준서의 한 달」— 상황 선택형, 단원 단위 (선택)
4. 금융 도감 — 차시 통과마다 낱말 카드 수집 (선택)
5. 단원 보스전 — 단원 누적 문제, 보스 HP, 단원 확인 평가 연계 (선택)
6. 반 대항 퀴즈쇼 — 교실 TV + 크롬북 실시간 (고르지 않음)

- 교사: https://biscuitbox.github.io/Finance-and-the-Future/game/teacher.html

## 금고 규칙 (18차시가 본보기)
- 자물쇠 5개: 개념(4지선다) · 순서 · 분류(보호 O/X) · 계산① (보호 한도) · 계산② (대출 상계 / 지점 합산)
- 틀리면 8초 → 15초 잠김 + 힌트, 풀리면 **다른 문제**(숫자 변형)
- 별: 한 번에 연 자물쇠 5개 ★★★, 3~4개 ★★, 그 외 ★
- 교사 화면: 통과 현황, 자물쇠별 '한 번에 맞힌' 비율, 학생별 시도, 마지막 방 글 모아 보기, 전 차시 매트릭스, TV 진행판(번호만), CSV, 기록 풀기

## 다른 선생님 사용
- A. 함께 쓰기: 관리자가 교사 화면 '선생님 관리'에 구글 이메일 등록 → 각자 반 만들기
- B. 다른 학교: 저장소 Fork + 자기 Firebase
