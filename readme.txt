금융과 미래 수업 키트 — 사용 안내
=====================================

■ 올릴 파일 (이 세 개만 GitHub 저장소에 올리면 됩니다)
  index.html      홈. 단원·차시 목록에서 슬라이드와 학습지로 이동
  slides.html     강의 슬라이드 (34차시)
  worksheet.html  학생 학습지 (34차시)
  세 파일은 같은 폴더에 두어야 서로 연결됩니다.

■ 차시별 주소
  슬라이드  …/slides.html#ch8     (8차시 첫 장)
  학습지    …/worksheet.html#ch8  (클래스룸 과제에 이 주소를 붙이세요)

■ 슬라이드 조작
  → / Space / 클릭   다음 장
  ←                  이전 장
  N                  발표자 노트 열기·닫기
  P                  발표자 창(노트·다음 장·타이머)을 새 창으로 — 교실 TV와 교사 화면을 나눌 때
  F                  전체 화면
  G                  차시 고르기
  마지막 장(학습지 활동)에서 [학습지 열기]를 누르면 그 차시 학습지로 갑니다.

■ 학습지
  · 학생이 쓴 내용은 그 크롬북 브라우저에만 저장됩니다(서버 전송 없음).
  · 다 쓰면 [워드 파일로 내려받기] 또는 [PDF로 저장하기] → 클래스룸에 파일로 제출.
  · 파일 이름: 금융과미래_8차시_학번_이름.docx
  · 18세 미만 학생이 제미나이를 쓰려면 학교 관리자가 Google Workspace 관리 콘솔에서 켜 두어야 합니다.

■ 수업 전에 확인할 것
  · 슬라이드의 실생활 수치(금리·물가 등)는 2026년 10월 5일 기준입니다.
    발표자 노트에 "수업 당일 확인" 안내가 있는 장은 최신 수치로 바꿔 주세요.
  · 교재와 내용이 다른 곳(예금자 보호 1억 원, 신용점수제, 국민연금 개혁 등)은
    발표자 노트에 "교재와 다름"으로 표시해 두었습니다.
  · 영상 슬라이드는 유튜브 검색 링크로 되어 있는 것이 많습니다. 수업 전에 쓸 영상을 골라 두세요.

■ 고쳐 쓰고 싶을 때 (편집용_원본 폴더)
  src/lessons/chNN.js 에 차시 내용이 있습니다. 고친 뒤
    python3 build.py
  를 실행하면 dist/ 에 세 파일이 새로 만들어집니다. 작성 규칙은 ref/AUTHORING.md.
