# 금고 탈출 — 설정과 다른 선생님 사용 안내

차시마다 금고(퀴즈 방탈출)를 풀어야 통과하는 학습 확인 게임입니다. 학생은 **반 코드 + 번호**로 들어오고(이름·이메일을 받지 않음), 선생님은 **구글 로그인**으로 자기 반 기록만 봅니다.

| 주소 | 누가 |
|---|---|
| `…/game/` | 학생 — 금고 지도, 차시 금고, 내 도감 |
| `…/game/teacher.html` | 선생님 — 반 만들기, 현황·마지막 방 글·전 차시 보기, TV 진행판, CSV |

Firebase를 연결하기 전에는 **체험 모드**로 작동합니다(기록이 그 브라우저에만 남음, 예시 반 코드 `DEMO01`).

---

## 1. 처음 한 번: Firebase 연결 (관리자 선생님, 약 15분)

1. https://console.firebase.google.com → **프로젝트 추가** (이름 예: `finance-vault`). 애널리틱스는 꺼도 됩니다.
2. **빌드 → Authentication → 시작하기 → 로그인 방법**에서 **Google**과 **익명**을 둘 다 사용 설정합니다.
3. Authentication → **설정 → 승인된 도메인**에 `biscuitbox.github.io`(사이트 주소의 도메인)를 추가합니다.
4. **빌드 → Firestore Database → 데이터베이스 만들기** → 위치 `asia-northeast3 (서울)` → **프로덕션 모드**.
5. Firestore → **규칙** 탭에 `game/firestore.rules` 내용을 그대로 붙여 넣고 **게시**합니다.
6. Firestore → **데이터** 탭 → 컬렉션 시작: 컬렉션 ID `teachers`, 문서 ID에 **내 구글 이메일(소문자)**, 필드 `admin` (boolean) = `true`, `name` (string) = 내 이름. → 이것으로 내가 관리자가 됩니다.
7. **프로젝트 설정(톱니) → 일반 → 내 앱 → 웹(</>)** 으로 앱을 등록하고, 나오는 `firebaseConfig` 값을 `game/firebase-config.js`의 `window.FIREBASE_CONFIG = { … }` 자리에 붙여 넣어 저장소에 올립니다.
8. `…/game/teacher.html`에서 로그인 → **새 반 만들기** → 나온 6자리 반 코드를 학생에게 알려 줍니다.

> firebaseConfig 값은 공개되어도 괜찮습니다. 누가 무엇을 읽고 쓸 수 있는지는 5번의 보안 규칙이 정합니다.

무료 요금제(Spark)로 충분합니다. 학생 한 명이 금고 하나를 풀 때 약 8~10번 기록하므로, 하루에 금고 2,000판 정도까지는 무료 한도 안입니다.

## 2. 다른 선생님이 쓰는 방법

### 방법 A — 이 사이트를 함께 쓰기 (같은 학교·같은 과목 선생님께 추천)
1. 선생님이 `…/game/teacher.html`에서 구글로 로그인하면 "등록되지 않은 선생님" 화면에 이메일이 보입니다.
2. 관리자가 교사 화면 **선생님 관리**에 그 이메일을 등록합니다.
3. 그 선생님은 새로고침 → **새 반 만들기** → 자기 반 코드를 학생에게 알려 줍니다.
4. 선생님마다 **자기가 만든 반의 기록만** 보입니다(보안 규칙으로 막혀 있음).

설치·설정이 전혀 없는 대신, 모든 반의 학생 기록(반·번호·답·마지막 방 글)이 **관리자의 Firebase에 모입니다.** 다른 학교 선생님까지 받으려면 방법 B를 권합니다.

### 방법 B — 우리 학교용으로 따로 만들기 (다른 학교 선생님께 추천)
1. GitHub에서 이 저장소를 **Fork**(내 계정으로 복사) → Settings → Pages → `main` 브랜치 루트로 켭니다.
2. 위 1장의 1~8을 그 선생님의 구글 계정으로 따라 합니다(승인된 도메인은 `내아이디.github.io`).
3. 기록은 그 학교 선생님의 Firebase에만 저장되고, 관리도 그 학교가 합니다.

## 3. 학생 개인정보와 기록 관리
- 받는 정보: 반 코드, 번호, 자물쇠별 시도 횟수, 걸린 시간, 마지막 방 1~2줄 글. 이름·이메일·학번은 받지 않습니다.
- 학생은 익명 로그인이라 구글 계정 정보가 남지 않습니다. 같은 번호는 **처음 시작한 기기만** 이어서 쓸 수 있어, 다른 학생 번호로 대신 기록할 수 없습니다(막히면 교사 화면 '기록 풀기').
- 학년이 끝나면 교사 화면의 **반 삭제**로 그 반 기록을 모두 지웁니다.
- 학교에서 외부 서비스로 학생 정보를 처리할 때 정한 절차(정보 담당·개인정보 담당 확인)가 있다면 그에 따릅니다.

## 4. 새 차시 금고 만들기
- `game/data/ch18.js`를 본보기로 `chNN.js`를 만들고, `game/chapters.js`의 `READY`에 번호를 넣습니다.
- 자물쇠 문제 형식: `choice`(4지선다) · `order`(순서) · `sort`(두 갈래 분류) · `number`(계산, `gen`으로 숫자를 바꿔 냄).
- 한 자물쇠에 문제를 **2개 이상**(또는 `gen`) 두어야, 틀린 뒤 다른 문제가 나와 찍어서 통과하기 어렵습니다.
