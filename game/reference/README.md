2026. 11. 16. 다른 작업에서 생긴 게임 구상 파일을 참고용으로 옮겨 둔 것이다. 지금 금고 탈출(`game/index.html`, `game/teacher.html`)은 이 파일들을 읽지 않는다.

- `firebase-config.js` — 같은 구상의 Firebase 설정 틀(`window.FM_FIREBASE`). 실제 설정은 `game/firebase-config.js`에 넣는다
